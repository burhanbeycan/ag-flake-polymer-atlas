## Runtime regression discovered during validation

The previous timeout implementation stopped only the immediate process and
could leave launcher children running. A local reproducer confirmed the leak.
The runner now isolates POSIX jobs, sends a graceful termination to the MPI
launcher, kills remaining processes in its group, and reaps the launcher on
timeout or terminal cancellation. The timeout remains visible in the output
and collection status. A real two-rank `mpirun` cleanup check also released
both test rank locks. The complete software suite passed **33 tests** after
the fix; existing ASE/NumPy deprecation warnings remain.
